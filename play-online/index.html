Online Duel

Race one other player on the same image.

Both players get the exact same image, it starts absurdly zoomed in, and every 15 seconds the server zooms it out one step for both people at the same time. First correct guess wins the round.

What the match feels like

  • Same image order for both players.
  • Shared countdown before each round starts.
  • Automatic zoom-out every 15 seconds.
  • First valid guess wins the point.
  • Best-of-3 or best-of-5 match format.

What you would see

  • Your own image and guess box as the main focus.
  • An opponent panel with typing and recent guesses.
  • A timer for the next zoom-out step.
  • A live match score across rounds.

How it stays fair

  • The server decides the round seed and the reveal timestamps.
  • The server checks answers, not just the browser.
  • The server breaks ties by submission time.
  • Guess spam gets throttled.
Coming next

The realtime matchmaking backend is not live yet. The scalable build plan is documented in /docs/online-duel/.
